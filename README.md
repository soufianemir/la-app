# LÀ ?

MVP PWA mobile-first pour répondre à une question simple : **est-ce que ça vaut le coup d'y aller maintenant ?**

## MVP
- géolocalisation navigateur avec fallback Cannes
- plages proches dans les Alpes-Maritimes
- météo live via Open-Meteo, avec fallback hors-ligne
- score instantané “J'y vais ?”
- filtres tranquillité / famille / parking
- signalement express (stockage local pour cette première version)
- partage natif mobile
- PWA installable et cache hors-ligne

## Déploiement
Projet 100 % statique, compatible Vercel sans configuration serveur ni secret.

## Prochaine étape
Brancher une base communautaire gratuite afin que les signalements soient partagés entre tous les utilisateurs.
